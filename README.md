Features:

Two carousels — "Recommended For You" and "Top Picks in Electronics" — with left/right arrow navigation
Category Tabs (All, Electronics, Fashion, Home, Beauty) that filter the product cards
Scrollable chips row for sub-category filtering
Product cards with image, name, star rating badge, price, MRP, discount %, and offer tag
Hover effects — Add to Cart button slides up, image zooms, wishlist heart appears
Wishlist toggle — click the heart icon to save/unsave
Add to Cart feedback — turns green with a checkmark on click
Fully responsive for mobile screens
